# Bot Rede Sociais

Bot de afiliados do Mercado Livre. Posta 3 produtos por dia no Facebook, no Instagram e no Telegram.

Status: **planejamento**. Ainda não tem código. Leia `docs/ESPECIFICACAO.md`.

## Em um computador novo
1. Instale o Git e o Python.
2. `git clone https://github.com/kawzsilva7-star/Bot-Rede-Sociais`
3. Copie o arquivo `.env` guardado em lugar seguro para dentro da pasta.
4. Rode `scripts/instalar` (será criado na Fase 3).

As chaves ficam só no `.env`. Ele não vai para o GitHub, então guarde uma cópia no seu gerenciador de senhas.
