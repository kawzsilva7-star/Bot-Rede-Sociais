# Bot de afiliados

Leia `docs/ESPECIFICACAO.md` antes de qualquer coisa. Ele diz o que o bot faz, as regras e o que ainda precisa ser confirmado.

## Como trabalhar aqui
- Responda em português.
- O dono não é programador. Explique em linguagem simples e dê os comandos completos para colar.
- Pergunte antes de apagar, publicar, gastar dinheiro ou alterar algo fora desta pasta.
- Não escreva código antes de resolver os "Pontos a verificar" da especificação. Confira na documentação oficial e diga o que foi confirmado e o que não foi.
- Nunca coloque chaves, tokens ou senhas no código, no GitHub ou na conversa. Só no `.env`, que está no `.gitignore`.
- O bot começa em `DRY_RUN=true`. Postar de verdade só com aprovação do dono.
- Todo post identifica que é publicidade/afiliado e não inventa preço, desconto ou avaliação.
- O computador é Windows. Os comandos devem funcionar no PowerShell.
- Deixe tudo pronto para trocar de computador: `scripts/instalar` e README atualizados.
